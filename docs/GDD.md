## 1. 프로젝트 개요

### 1.1 프로젝트 한 줄 설명
> 게임처럼 탐험하는 아티스트 포트폴리오 웹사이트

### 1.2 장르 및 레퍼런스
| 항목 | 내용 |
|------|------|
| **장르** | 어드벤처 / 탐험 / 포트폴리오 |
| **시점 (외부)** | 고정 3/4 등각 투영 (Isometric/Oblique) |
| **시점 (내부)** | 2D 횡스크롤 (수평 카메라) |
| **카메라** | Follow Camera (플레이어 추적) |
| **주요 레퍼런스** | Paper Mario (외부 맵 시점), Undertale / Deltarune (상점 UI) |

### 1.3 목표 플랫폼
- 웹 브라우저 (PC 우선, 모바일 추후 고려)

### 1.4 개발 단계
| 단계 | 목표 | 포함 콘텐츠 |
|------|------|-------------|
| **프로토타입** (현재) | 핵심 게임플레이 검증 | 외부 맵, 재화 시스템, 시네마, 상점 |
| **정식 버전** (추후) | 전체 콘텐츠 완성 | 게시판, 집, 음원 시스템 등 추가 |

## 2. 게임플레이 구조

### 2.1 전체 흐름도

```
[타이틀 / 로딩]
        │
        ▼
[외부 맵 - Isometric 3D]
   ├── 맵 탐험 (이동, 점프)
   ├── 재화 수집 (숨겨진 코인/아이템)
   └── 건물 진입 (상호작용)
        │
        ├──▶ [게시판] ─── 방명록 UI (텍스트 + 그림판)
        │
        ├──▶ [시네마] ─── 2D 내부 맵
        │                   └── NPC 상호작용 → 미디어 목록 → 영상 재생
        │
        ├──▶ [상점] ──── RPG 상점 UI
        │                   └── Buy / Sell / Talk / Quit
        │
        └──▶ [집] ────── 2D 내부 맵
                           ├── 일기장 오브젝트 → 아티스트 프로필/경력
                           └── 턴테이블 오브젝트 → 음원 재생기
```

### 2.2 조작 방식
- **외부 맵**: WASD 키보드 이동
- **내부 맵**: WASD 키보드 이동
- 점프: 추후 결정 필요 (Space 키 등)

## 3. 외부 맵 (Isometric World)

### 3.1 시각 스타일
- **투영 방식**: 3/4 등각 투영 (Isometric 또는 Oblique)
- **카메라**: 플레이어를 따라가는 Follow Camera, 각도 고정
- **아트 스타일**: **픽셀아트 (도트 그래픽, 레트로 게임 감성)**
- **색감 / 테마**: **흑백 (Black & White)** — 무채색 기반 모노크롬 팔레트
  - 강조색(Accent) 사용 여부: 미정 (특정 상호작용 요소에만 컬러 포인트 부여 고려 가능)

### 3.2 맵 구성 요소
| 요소 | 설명 |
|------|------|
| 건물 오브젝트 | 게시판, 시네마, 상점, 집 |
| 지형 | 도로, 광장 등 이동 가능한 바닥 |
| 장식 오브젝트 | 나무, 가로등 등 분위기 연출용 |
| 수집 아이템 | 숨겨진 재화(코인 등), 숨겨진 앨범 |
| 점프맵 요소 | 플랫폼, 이동 장애물 등 |

### 3.3 수집 요소 (재화 시스템)
- **기본 재화**: 코인 (명칭 미정)
- **특수 아이템**: 숨겨진 앨범 (집의 턴테이블 콘텐츠 해금용)
- **수집 방법**: 맵 곳곳에 숨겨져 있으며, 점프맵 등 플레이 도전 요소와 연계

## 4. 건물 상세 기획

### 4.1 게시판 (Bulletin Board)
> **프로토타입 제외**

- 별도의 2D 내부 맵 없이, UI 레이어로만 구성
- **기능**:
  - 텍스트 방명록 작성 및 열람
  - 그림판 기능으로 그림 방명록 작성
- **데이터**: 접속자가 남긴 방명록이 저장되어야 함 → 백엔드/DB 필요

---

### 4.2 시네마 (Cinema)
> **프로토타입 포함** ✅

#### 진입 구조
1. 외부 맵에서 건물과 상호작용하여 진입
2. 시점이 **2D 횡스크롤**로 전환
3. 2D 내부 맵에서 자유 이동

#### 내부 구성
- **NPC**: 시네마 내부에 위치, 상호작용 가능
- **미디어 선택 UI**: NPC 상호작용 시 아래 형식의 목록 표시
  - 미디어 작품명
  - 짧은 부가 설명 (예: 제작 의도, 기법 등)
- **영상 재생 화면**:
  - 재생 시 배경 변환 (시네마 분위기 연출)
  - 화면 중앙에 영상 재생
  - 화면 하단 **레이어 버튼**: 현재 재생 영상의 상세 설명 표시 (슬라이드업 / 오버레이 형식)

- **영상 소스**: 직접 영상 파일 업로드 방식 사용 (mp4 등 로컬/서버 파일)
- 영상 파일은 프로젝트 내 폴더에 보관

---

### 4.3 상점 (Shop)
> **프로토타입 포함** ✅

#### 레퍼런스
- Undertale / Deltarune 상점 UI 스타일
- 텍스트 박스 중심의 레트로 RPG 감성

#### 메뉴 구성
| 선택지 | 기능 |
|--------|------|
| **Buy** | 상점 아이템 구매 목록 표시, 보유 재화로 구매 |
| **Sell** | 보유 아이템 판매 목록 표시, 재화 획득 |
| **Talk** | 상점 주인 NPC와 대화 |
| **Quit** | 상점 나가기 |

#### 판매 아이템 목록 (예시, 확정 필요)
> ⚠️ **결정 필요**: 구체적인 아이템 목록, 가격 설정

| 아이템 | 역할 | 예상 가격 |
|--------|------|-----------|
| 앨범 A | 집 턴테이블 음원 해금 | 미정 |
| 앨범 B | 집 턴테이블 음원 해금 | 미정 |
| (추가 예정) | | |

---

### 4.4 집 (House)
> **프로토타입 제외**

#### 진입 구조
- 외부 맵에서 건물과 상호작용하여 진입
- 시점이 **2D 횡스크롤**로 전환

#### 내부 오브젝트
| 오브젝트 | 상호작용 결과 |
|----------|---------------|
| **일기장** | 아티스트 프로필 표시 (전문분야, 경력, 소개 등) |
| **턴테이블** | 음원 재생기 UI 표시 |

#### 음원 시스템
- 상점에서 앨범 구매 또는 외부 맵에서 숨겨진 앨범 수집 → 해금
- 해금된 앨범만 턴테이블에서 재생 가능
- 재생기 UI: 재생/정지, 곡 목록 표시 등

## 5. 인벤토리 / 경제 시스템

### 5.1 재화
| 항목 | 내용 |
|------|------|
| 재화 명칭 | 미정 (코인, 별 등) |
| 획득 방법 | 외부 맵 탐험 중 수집 |
| 사용처 | 상점에서 아이템 구매 |

### 5.2 아이템 인벤토리
- 수집한 아이템(앨범 등) 보관
- 인벤토리 UI: 미정

### 5.3 세이브 / 데이터 저장
- **localStorage 사용**: 브라우저가 데이터를 자동으로 기억
- 재화 수집, 아이템 구매/획득 시 자동 저장
- 로그인 불필요, 같은 브라우저에서 접속 시 유지
